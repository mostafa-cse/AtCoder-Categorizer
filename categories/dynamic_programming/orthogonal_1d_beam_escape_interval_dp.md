# Knapsack and Basic Dynamic Programming

**Taxonomy Path**: `Dynamic Programming (DP)` > `Intro to DP` > `Knapsack and Basic Dynamic Programming`

## Description
This topic focuses on knapsack and basic dynamic programming techniques for solving competitive programming problems.

## Key Invariants & Techniques
- Invariants: Vertical beams restrict only X coordinates and horizontal beams restrict only Y coordinates, rendering movement costs along X and Y completely decoupled and independent.
- Common Reductions: In a $W \times H$ grid with $Q$ horizontal and vertical beams appearing at integer times, find the minimum number of steps to avoid all beams or report -1.
