# 2 SAT

**Taxonomy Path**: `Graph Theory` > `Satisfiability` > `2 SAT`

## Description
This topic focuses on 2 sat techniques for solving competitive programming problems.

## Key Invariants & Techniques
- Invariants: By universal algebra / clone theory, relations invariant under a majority (median) polymorphism are exactly 2-ary (binary clauses in 2-SAT). Therefore, a binary string $T$ can be generated by iterated median operations if and only if for every pair of coordinates $(j, k)$, the 2-bit projection $(T_j, T_k)$ appears in the initial set of strings.
- Common Reductions: Given $N$ vectors of length $M$ over $\{0, 1, 2\}$, determine if the set of vectors is closed under componentwise majority operation $m(x, y, z)$.
