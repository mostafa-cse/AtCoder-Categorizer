# Konig's Theorem and Maximum Independent Set in Bipartite Graphs

**Taxonomy Path**: `Graph Theory` > `Matching` > `Konig's Theorem and Maximum Independent Set in Bipartite Graphs`

## Description
This topic focuses on konig's theorem and maximum independent set in bipartite graphs techniques for solving competitive programming problems.

## Key Invariants & Techniques
- Invariants: The conflict graph generated by symmetric displacement vectors in $\mathbb{Z}^2$ is bipartite for any $A, B$ because any closed cycle must sum to $(0, 0)$ in displacements, which requires an even number of steps. Finding the maximum number of non-attacking pieces on a bipartite graph is the Maximum Independent Set problem. By König's theorem, $\text{MIS} = |V| - \text{Max Matching}$. The actual independent set can be reconstructed by finding the residual reachability from the source in the Dinic flow network: vertices of color 0 that are reachable, and vertices of color 1 that are unreachable.
- Common Reductions: On an $N \times N$ grid with wall cells `#` and empty cells `.`, we want to place the maximum number of pieces such that no two pieces attack each other using $(A, B)$ or $(B, A)$ displacement vectors. We also need to output one such maximum placement.
