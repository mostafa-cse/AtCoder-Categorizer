# Breadth First Search (BFS)

**Taxonomy Path**: `Graph Theory` > `Graph Traversal` > `Breadth First Search (BFS)`

## Description
This topic focuses on breadth first search (bfs) techniques for solving competitive programming problems.

## Key Invariants & Techniques
- Invariants: Any closed walk length is a multiple of $g = \gcd_{(u, v)} |d[u] + 1 - d[v]|$. A walk of length $10^{10^{100}}$ exists if and only if $g > 0$ and $g$ divides $10^{10^{100}}$, which means the only prime factors of $g$ are 2 and 5! If $g$ reduced by factors of 2 and 5 equals 1, answer is Yes, else No.
- Common Reductions: Determine if there is a closed walk from 1 to 1 of length $10^{10^{100}}$ in a directed graph. A vertex $v$ can participate in the walk if and only if it is in the Strongly Connected Component of 1 (reachable from 1 and can reach 1), found via two BFS runs on $G$ and $G^{rev}$. In this induced subgraph, run BFS from 1 to assign depth $d[v]$. The set of cycle lengths is generated by edges $u \to v$ with length $d[u] + 1 - d[v]$.
