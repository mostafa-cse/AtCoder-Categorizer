# Probabilities and Expected Values

**Taxonomy Path**: `Math` > `Probabilities and Expected Values` > `Probabilities and Expected Values`

## Description
This topic focuses on probabilities and expected values techniques for solving competitive programming problems.

## Key Invariants & Techniques
- Invariants: A vertex u is surrounded iff u not in S and u lies in the minimal connected subtree spanning S. Node u is on a path between two nodes in S iff at least two connected components of T \ {u} contain vertices from S. The complement is that at most one component contains vertices from S.
- Common Reductions: Linearity of expectation on tree nodes with complement probability of minimal Steiner tree containment.
