# Contribution Technique

**Taxonomy Path**: `Combinatorics` > `Techniques` > `Contribution Technique`

## Description
This topic focuses on contribution technique techniques for solving competitive programming problems.

## Key Invariants & Techniques
- Invariants: A graph represents a valid configuration of cards if and only if every connected component has at least 3 vertices or is a non-isolated edge structure without isolated $K_2$ components.
- Common Reductions: In a card game with $N$ vertices and $N$ edge cards of weights $C_i$, find a subgraph where every connected component has size at least 3 or is an edge without isolated single edges, minimizing total edge cost.
