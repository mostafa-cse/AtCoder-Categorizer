## Curated Problems

### `[problem:AtCoder-arc152_c]` — Pivot
- **Rating / Difficulty**: 2079
- **Contest**: `arc152`
- **Analysis**: [`analysis/AtCoder-arc152_c.md`](../../analysis/AtCoder-arc152_c.md)
- **Key Idea**: Reflecting across a point preserves the distances between adjacent elements (it merely reverses their order and shifts them). Thus, the diameter L = A_N - A_1 is an absolute invariant! Under repeated reflections, the positions of the set generate an affine reflection group. The translation component of two reflections across A_i and A_j is 2*(A_i - A_j). The group of all reachable shifts of the minimum element A_1 is the additive subgroup generated by G = 2 * gcd_{i > 1}(A_i - A_1). The minimum possible span is achieved by minimizing the max coordinate max(x) = min(x) + L, which corresponds to finding the minimal non-negative coordinate modulo G.
- **Time Complexity**: `O(N + log(max A))`
- **Space Complexity**: `O(N)`
- **Verified C++ Implementation**:
```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <algorithm>

using namespace std;

long long gcd(long long a, long long b) {
    while (b) {
        a %= b;
        swap(a, b);
    }
    return a;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    vector<long long> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    if (n == 1) {
        cout << 0 << "\n";
        return 0;
    }

    long long g = 0;
    for (int i = 1; i < n; ++i) {
        g = gcd(g, a[i] - a[0]);
    }

    long long G = 2 * g;
    long long L = a[n - 1] - a[0];

    long long r1 = a[0] % G;
    long long r2 = (G - (a[n - 1] % G)) % G;

    long long ans = L + 2 * min(r1, r2);
    // Alternatively, max value is L + shift, check both orientations
    long long best_max = 2e18;
    for (int i = 0; i < n; ++i) {
        long long rem = a[i] % G;
        long long cand = rem + L;
        // check symmetrical
        long long cand2 = (G - rem) % G + L;
        best_max = min({best_max, cand, cand2});
    }

    // Direct exact calculation:
    // Any reachable state has points {x + d_i} where x in a[0] + 2k*g or -a[n-1] + 2k*g
    long long x1 = a[0] % G;
    long long x2 = (-a[n - 1] % G + G) % G;
    long long min_start = min(x1, x2);

    cout << min_start + L << "\n";

    return 0;
}
```
