# Euler's Totient Function / Phi Function

**Taxonomy Path**: `Number Theory` > `Multiplicative Functions` > `Euler's Totient Function / Phi Function`

## Description
This topic focuses on euler's totient function / phi function techniques for solving competitive programming problems.

## Key Invariants & Techniques
- Invariants: In the cyclic group (Z/PZ)*, A_j is a power of A_i iff the cyclic subgroup generated by A_j is contained in that of A_i, which holds iff ord(A_j) divides ord(A_i).
- Common Reductions: Given N integers A_i and a prime P <= 10^{13}, count pairs (i, j) such that A_i^k = A_j mod P for some positive integer k.
