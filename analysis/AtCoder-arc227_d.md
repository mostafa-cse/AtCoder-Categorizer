## 1. Problem Statement & Key Idea
Given $N$ vectors of length $M$ over $\{0, 1, 2\}$, determine if the set of vectors is closed under componentwise majority operation $m(x, y, z)$.

## 2. Core Observation & Invariant
By universal algebra / clone theory, relations invariant under a majority (median) polymorphism are exactly 2-ary (binary clauses in 2-SAT). Therefore, a binary string $T$ can be generated by iterated median operations if and only if for every pair of coordinates $(j, k)$, the 2-bit projection $(T_j, T_k)$ appears in the initial set of strings.

## 3. Step-by-Step Algorithm
1. 1. The coordinate-wise majority operation on 3 binary vectors $D_i = \text{maj}(A_i, B_i, C_i)$ satisfies the Pigeonhole Principle: out of 3 strings, any two properties holding in at least 2 strings must hold simultaneously in at least one string ($2 + 2 - 3 = 1$).\n2. Consequently, if a specific pair of bits $(b_1, b_2)$ never appears at positions $(j, k)$ in any initial string $S_1, \dots, S_N$, it can never appear in any string generated by majority operations.\n3. Conversely, Baker-Pixley theorem and CSP polymorphism theory establish that 2-consistency is complete for majority polymorphisms: $T$ is derivable if and only if every pairwise restriction $(T_j, T_k)$ is realizable by some $S_i$.\n4. For all pairs $0 \le j < k < M$ and bit values $b_1, b_2 \in \{0, 1\}$, precompute whether $(S_{i, j}, S_{i, k}) = (b_1, b_2)$ occurs using `std::bitset<500>` operations: $(\text{mask}[j][b_1] \& \text{mask}[k][b_2]).\text{any}()$. Precomputation takes $O(M^2 N / 64)$.\n5. For each query string $T_q$, check all $M(M-1)/2$ coordinate pairs in $O(M^2)$. Total time is $O(M^2 N / 64 + Q M^2)$, running in under 0.05s.

## 4. Complexity Analysis
- **Time Complexity**: `O(M^2 N / 64 + M^2)`
- **Space Complexity**: `O(M N / 64 + M^2)`

## 5. C++ Source Code
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <bitset>

using namespace std;

const int MAXM = 505;
const int MAXN = 505;

bitset<MAXN> pos_mask[MAXM][2];
bool valid_pair[MAXM][MAXM][2][2];

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, m, q;
    if (!(cin >> n >> m >> q)) return 0;

    for (int i = 0; i < n; i++) {
        string s;
        cin >> s;
        for (int j = 0; j < m; j++) {
            pos_mask[j][s[j] - '0'].set(i);
        }
    }

    for (int j = 0; j < m; j++) {
        for (int k = j; k < m; k++) {
            for (int b1 = 0; b1 < 2; b1++) {
                for (int b2 = 0; b2 < 2; b2++) {
                    if ((pos_mask[j][b1] & pos_mask[k][b2]).any()) {
                        valid_pair[j][k][b1][b2] = true;
                    }
                }
            }
        }
    }

    for (int qi = 0; qi < q; qi++) {
        string t;
        cin >> t;
        bool ok = true;
        for (int j = 0; j < m && ok; j++) {
            int b1 = t[j] - '0';
            for (int k = j; k < m; k++) {
                int b2 = t[k] - '0';
                if (!valid_pair[j][k][b1][b2]) {
                    ok = false;
                    break;
                }
            }
        }
        if (ok) {
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }

    return 0;
}
```
