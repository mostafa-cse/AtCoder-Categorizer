## 1. Problem Statement & Key Idea
An integer n is a Snuke number if for all m > n, n / S(n) <= m / S(m), where S(x) is the sum of digits of x in base 10. Output the first K Snuke numbers in ascending order.

**Key Idea**: Between n and larger integers, the next candidate Snuke number is always obtained by incrementing some power of 10: n + 10^p. For large numbers, suffixes of 9s yield smaller ratios m / S(m). By maintaining the current Snuke number cur, we evaluate candidate numbers cur + 10^p for all 0 <= p <= 14. We pick the candidate that minimizes candidate / S(candidate). Repeating this greedily generates all Snuke numbers up to K.

## 2. Core Observation & Invariant
Extending lower digits with 9s dominates arbitrary jumps; candidates generated by cur + 10^p for all digit positions cover all potential next Snuke numbers.

## 3. Step-by-Step Algorithm
1. Initialize cur = 1, count = 0.
2. While count < K:
3.   Print cur; count++.
4.   If count == K: break.
5.   Generate candidates: for p from 0 to 14, let cand = cur + 10^p.
6.   Find candidate that minimizes (double)cand / S(cand) (with tie-breaker: smaller cand).
7.   Update cur = best_cand.

## 4. Complexity Analysis
- **Time Complexity**: `O(K * 15 * log10(X))`
- **Space Complexity**: `O(1)`

## 5. Core Algorithmic Skill & Learning Takeaway
Digit ratio greedy progression on base-10 representations.

**Reusable Pattern**: Base-10 Suffix Minimization: Testing cur + 10^p over all digit positions to greedily find the next ratio extremum.

## 7. Verified Clean C++ Source Code
```cpp
#include <iostream>
#include <vector>
#include <cstdint>

using namespace std;

long long digit_sum(long long x) {
    long long s = 0;
    while (x > 0) {
        s += x % 10;
        x /= 10;
    }
    return s;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int k;
    if (!(cin >> k)) return 0;

    long long cur = 1;
    vector<long long> pow10(16);
    pow10[0] = 1;
    for (int i = 1; i <= 15; ++i) {
        pow10[i] = pow10[i - 1] * 10;
    }

    for (int step = 0; step < k; ++step) {
        cout << cur << "\n";
        long long best_cand = cur + 1;
        double best_val = (double)best_cand / digit_sum(best_cand);

        for (int p = 0; p <= 14; ++p) {
            long long cand = cur + pow10[p];
            double val = (double)cand / digit_sum(cand);
            if (val < best_val) {
                best_val = val;
                best_cand = cand;
            }
        }
        cur = best_cand;
    }

    return 0;
}
```
